SECTION 1: BUBBLE COLORS - Gradient from Center to Edge
================================================================================

A realistic bubble uses this color progression (QRadialGradient):

    CENTER (0%)          MID-TONE (40%)       DARKER (70%)        RIM (100%)
    White                Cyan                 Blue                Shadow
    ─────────────────────────────────────────────────────────────────────────
    RGB: 255,255,255     RGB: 100,200,255     RGB: 50,150,200     RGB: 30,80,150
    Alpha: 255           Alpha: 220           Alpha: 180          Alpha: 100
    HEX: #FFFFFF         HEX: #64C8FF         HEX: #3296C8        HEX: #1E5096
    ─────────────────────────────────────────────────────────────────────────

    Visual effect:
    [WHITE] ──→ [CYAN] ──→ [DARKER BLUE] ──→ [NAVY SHADOW]
     (Bright)            (Aquatic)            (Depth)

This creates the appearance of light reflecting off a water sphere.

SECTION 3: WET SURFACE EFFECT LAYER BREAKDOWN
================================================================================

To create the "wet" appearance, layer these elements:

LAYER 1 - BASE COLOR GRADIENT
    Top:    Light version of main color
    Bottom: Dark version of main color
    Effect: Creates dimensional base

LAYER 2 - FROSTED GLASS OVERLAY
    Color: White (255, 255, 255)
    Alpha: 35% (90 out of 255)
    Effect: Makes surface appear covered with water droplets
            This is THE key effect that makes it look "wet"

LAYER 3 - SPECULAR HIGHLIGHT
    Color: White to light cyan gradient
    Start:  255, 255, 255 (white) at 200 alpha
    End:    100, 200, 255 (light cyan) at 0 alpha
    Size:   ~25% width × 15% height
    Position: 30-40% from top-left
    Effect: Bright reflection spot (like light bouncing off wet surface)

LAYER 4 - SOFT SHADOW BELOW
    Color: Black (0, 0, 0)
    Alpha: 60 (dark with 20-25% opacity)
    Position: Bottom 20% of surface
    Effect: Adds depth perception, grounds the element


STACKING DIAGRAM:

    ┌─────────────────────────────────────┐
    │ LAYER 4: Soft Shadow (bottom)       │
    │ (Black, fades in, Multiply blend)   │
    ├─────────────────────────────────────┤
    │ LAYER 3: Specular Highlight         │
    │ (Bright white, tight gradient)      │
    ├─────────────────────────────────────┤
    │ LAYER 2: Frosted Overlay            │
    │ (White, 35% opacity - MOST VISIBLE) │
    ├─────────────────────────────────────┤
    │ LAYER 1: Base Color Gradient        │
    │ (Light to dark blue/cyan)           │

SECTION 7: ALPHA/OPACITY QUICK REFERENCE
================================================================================

Common opacity levels (out of 255):

    Visual Effect              Alpha Value    Percentage    Use For
    ─────────────────────────────────────────────────────────────────────────
    Fully opaque              255             100%          Main colors
    Mostly opaque             220             86%           Bubble mid-tone
    Semi-transparent          180             71%           Bubble outer
    Medium transparent        90              35%           Frosted overlay
    Mostly transparent        50              20%           Soft shadow
    Very transparent          0               0%            Fade out


Convert between formats:
- Percentage to 0-255: percentage × 2.55 = alpha
- Alpha to percentage: alpha ÷ 2.55 = percentage
- Example: 35% opacity = 35 × 2.55 = 89 ≈ 90 alpha
