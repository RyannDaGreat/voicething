KEY RESEARCH FINDINGS
================================================================================

WINAMP CLASSIC (Audio Tech Foundation):
  - Iconic lime green waveform: #00FF00 (pure RGB: 0, 255, 0)
  - Dark background: #1a1a1a or #121212 (deep near-black)
  - Visualization types: Spectrum analyzer bars + oscilloscope waveform
  - Color animation: Bars decay at different speeds with peak glow
  - Fonts: MS Sans Serif (modern alternative: Verdana)
  - Use case: Waveform display, technical elements, real-time visualization

WINDOWS 95 (UI Framework):
  - ButtonFace: #C0C0C0 (192, 192, 192) - silver-gray button base
  - ButtonHighlight: #FFFFFF (255, 255, 255) - top/left beveling
  - ButtonShadow: #808080 (128, 128, 128) - bottom/right beveling
  - ButtonDkShadow: #000000 (0, 0, 0) - deep shadow for 3D effect
  - Beveling technique: border-style outset/inset or manual border colors
  - Use case: Button styling, main window, familiar interface foundation

Y2K AESTHETIC (Futuristic Shine):
  - Core colors: Chrome silver, gold, metallic gradients
  - Gradient approach: Linear or radial from bright to darker tones
  - Metallic effect: #FFFFFF → #C0C0C0 → #808080
  - Gold accents: #FFD700 (255, 215, 0) for highlights
  - Bright silver: #E8E8E8 for hover states
  - Visual elements: Gloss effects, transparency, rounded corners (sparingly)
  - Use case: Button shine, important controls, accent highlights

VAPORWAVE AESTHETIC (Dream Neon):
  - Primary palette: Hot pink, cyan, purple, mint, pale yellow
  - Hot pink: #FF71CE (255, 113, 206)
  - Cyan: #01CDFE (1, 205, 254)
  - Purple: #B967FF (185, 103, 255)
  - Mint green: #05FFA1 (5, 255, 161)
  - Pale yellow: #FFFB96 (255, 251, 150)
  - Best technique: Gradients for spectrum visualization
  - Use case: Visualization gradients, secondary accents, artistic elements

================================================================================
DESIGN PRINCIPLES (Making It "Pretty Not Retro-Ugly")
================================================================================

DO:
  + Use full color palette but not all at once
  + Let dark panels dominate (reduces eye strain, looks professional)
  + Use bright accents strategically (#00FF00 for waveforms, #FFD700 for buttons)
  + Combine smooth gradients with Win95 beveling
  + Make visualization the focal point (animated, colorful, alive)
  + Use subtle effects sparingly (less is more in retro design)
  + Ensure high contrast for readability

DON'T:
  - Use loud vaporwave colors on large backgrounds
  - Combine heavy bevels + heavy shadows everywhere
  - Use pale colors on Winamp-dark backgrounds
  - Apply Y2K metallics to everything (only buttons/highlights)
  - Make text too small trying to fit retro aesthetic
  - Use pure white (#FFFFFF) text on pure black (hard on eyes)
  - Mix too many accent colors on same UI

QUALITY CHECKLIST:
  ☐ Waveform clearly visible and animated smoothly
  ☐ All text is readable at normal viewing distance
  ☐ Colors are intentional, not random
  ☐ Buttons feel responsive with clear visual feedback
  ☐ Dark areas don't blend with each other
  ☐ Bright accents draw eye to important controls
  ☐ Gradients are subtle, not overwhelming
  ☐ Overall layout is clean and organized

================================================================================
TYPOGRAPHY RECOMMENDATIONS
================================================================================

PRIMARY FONT: Verdana
  - Designed for screens in 1990s
  - Highly legible at small sizes
  - Available system-wide
  - Size: 10-11pt for normal text, 9pt for labels

MONOSPACE (Technical Display): Consolas
  - Modern monospace, clear rendering
  - For time codes, file info, technical readouts
  - Size: 9-10pt, bold weight recommended

ALTERNATIVE/Y2K FEEL: Futura or Montserrat
  - Geometric sans-serif, futuristic
  - For titles and accents (not body text)
  - Size: 12pt+ for headers

AVOID:
  - Thin/light weights (hard to read at small sizes)
  - Sans-serif fonts smaller than 9pt
  - Too many font variations (stick to 2-3 max)

================================================================================
VISUALIZATION IMPLEMENTATION DETAILS
================================================================================

SPECTRUM ANALYZER (Recommended):
  - 32-64 vertical frequency bins
  - Bar width: 3-4 pixels with 2px gaps
  - Height: represents amplitude at that frequency
  - Color: gradient from cyan (#01CDFE) to purple (#B967FF)
  - Animation: smooth falloff (bars decay, don't snap to zero)
  - FFT-based (Fast Fourier Transform for frequency analysis)
  - Update rate: 30-60 FPS

WAVEFORM DISPLAY (Optional Secondary):
  - Raw sample-by-sample visualization
  - Connected line or dots showing amplitude over time
  - Color: #00FF00 (Winamp classic lime green)
  - Display: 1024-2048 samples at a time
  - More CPU-intensive but more "analog" looking
  - Update rate: with each audio buffer

LEVEL METERS (Essential):
  - Dual-channel (L/R) or mono display
  - Current level bar + peak indicator
  - Colors: gradient from cyan to pink, or mint green
  - Peak decay animation (slowly falls over time)
  - Text labels: "L" and "R" in white
  - Update rate: 30-60 FPS
