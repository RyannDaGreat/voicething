## Text Color Rules (For Accessibility)

### Light Backgrounds (#C0C0C0, #FFFFFF, #E8E8E8)
| Text Color | Contrast Ratio | Grade | Notes |
|-----------|---|---|---|
| #000000 | 8.5:1 | AAA | BEST - Maximum contrast |
| #800000 | 5.5:1 | AA | Good - Dark red |
| #808080 | 3.5:1 | — | Fair - Gray (secondary) |
| #FFFFFF | 1:1 | FAIL | Invisible |
| #FFD700 | 3.5:1 | — | Fair - Title only |

### Dark Backgrounds (#1a1a1a, #121212, #000000)
| Text Color | Contrast Ratio | Grade | Notes |
|-----------|---|---|---|
| #FFFFFF | 21:1 | AAA | BEST - Maximum contrast |
| #FFD700 | 8.5:1 | AAA | Excellent - Gold titles |
| #00FF00 | 6.5:1 | AA | Good - Lime green tech text |
| #01CDFE | 7.5:1 | AAA | Excellent - Cyan labels |
| #FF71CE | 5.5:1 | AA | Good - Pink accents |
| #000000 | 1:1 | FAIL | Invisible |

### Recommendations
- Use #FFFFFF for body text on dark backgrounds (most readable)
- Use #FFD700 for titles/headings on dark backgrounds
- Use #00FF00 for technical/mono text on dark (maintains Winamp feel)
- Use #000000 for body text on light backgrounds
- Avoid gray (#808080) for primary text (too low contrast)
- Avoid bright colors for large text areas (eye strain)

## Color Harmony Notes

This palette works because:
1. **Dominant**: Win95 gray is neutral, professional, nostalgic
2. **Secondary**: Winamp dark provides contrast and tech feel
3. **Accent**: Lime green is instantly recognizable, stands out
4. **Highlight**: Gold adds Y2K shine without overwhelming
5. **Vaporwave**: Cyan/purple gradients complement both 90s and 80s nostalgia
6. **Beveling**: White/gray edges create Win95 3D illusion

The combination feels:
- **Retro but not cheap** (gold + gradients)
- **Technical but beautiful** (lime on dark + vaporwave)
- **Familiar yet unique** (Win95 base + 80s/2000s accents)
- **Functional and intentional** (all colors serve a purpose)
