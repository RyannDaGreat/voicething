================================================================================
BUBBLE GRADIENT VISUAL GUIDE
Exact positioning and color stops for realistic water bubble effect
================================================================================

This guide shows exactly where colors go in your radial gradient to create
a convincing bubble/water droplet appearance.


================================================================================
PART 1: BUBBLE SPHERE ANATOMY
================================================================================

A realistic bubble has these visual zones:

        Highlight zone (bright white center)
              ↓
            ╭─────╮
          ╱ ░░░░░░░░░░ ╲         ░ = highlight (white center)
        ╱  ░░░░░░░░░░░░░  ╲      ▒ = mid-tone (cyan)
       │  ░ BUBBLE ▒▒▒  │      ▓ = darker edge (blue)
       │ ░░▒▒▒▒▒▒▒▒▒▒▓▓ │      ▓▓▓▓ = rim shadow
       │ ░▒▒▒▒▒▒▒▒▒▒▓▓▓ │
        ╲  ░▒▒▒▒▒▒▒▒▓▓▓  ╱

            ╰─────────╯


The gradient radiates from the highlight point (30% offset) outward.

WHAT THIS CREATES:

    Edge:      Dark blue (semi-transparent) - defines bubble boundary
    Rim:       Navy shadow (mostly transparent) - fades to nothing

================================================================================
PART 4: HIGHLIGHT OFFSET POSITIONING
================================================================================

The highlight doesn't appear at the bubble's center. It's offset to create
a 3D lighting effect.

For a bubble at position (x, y) with radius r:

    STANDARD LIGHTING (top-left light source):

    ╭─────────────────────────────────────────────────────╮
    │  Bubble Visual                                      │
    │                                                     │
    │   Highlight point:                                  │
    │   x_highlight = x + r × 0.3                         │
    │   y_highlight = y + r × 0.3                         │
    │                                                     │
    │   Result: Highlight is 30% from top-left corner     │
    │                                                     │
    │   This creates the appearance of light coming       │
    │   from the top-left (natural, like window light)    │
    ╰─────────────────────────────────────────────────────╯


EXAMPLE WITH NUMBERS:

Bubble: x=100, y=100, radius=30

    Center point: (100, 100)
    Highlight point: (100 + 30×0.3, 100 + 30×0.3) = (109, 109)

    The gradient radiates from (109, 109) outward 30 pixels
    This places the bright spot slightly down and to the right
    Creating natural 3D sphere appearance


VISUAL:

    Without offset (center highlight):
    ╭───────────╮
    │ ░░░░░░░░░ │  Looks flat, like a circle (not a sphere)
    │ ░░░░░░░░░ │
    │ ░░░░░░░░░ │
    ╰───────────╯

    With 30% offset (top-left highlight):
    ╭───────────╮
    │░░░░░░░░░░│  Looks 3D! Bright spot shows sphere shape
    │░░░░░░░░░░│  Natural lighting

    ╰───────────╯

PART 5: MULTIPLE BUBBLE SIZES
================================================================================

The gradient works at any size because it's proportional to radius:

SIZE    RADIUS    HIGHLIGHT OFFSET        GRADIENT RADIUS
═══════════════════════════════════════════════════════════════════════════
Small   8px       x + 8×0.3 = x + 2.4     8px
Medium  15px      x + 15×0.3 = x + 4.5    15px
Large   30px      x + 30×0.3 = x + 9      30px
Huge    50px      x + 50×0.3 = x + 15     50px

The colors stay the same, the proportions scale with size.

================================================================================
PART 6: CODE IMPLEMENTATION REFERENCE
================================================================================

Python code for bubble gradient (from aquatic_effects_example.py):

    from PyQt6.QtGui import QRadialGradient, QColor, QPointF

    # Bubble parameters
    x, y = 100, 100  # Center position
    radius = 30      # Bubble size

    # Create gradient with offset highlight
    highlight_x = x + radius * 0.3
    highlight_y = y + radius * 0.3
    gradient = QRadialGradient(QPointF(highlight_x, highlight_y), radius)

    # Add color stops
    gradient.setColorAt(0.0, QColor(255, 255, 255, 255))      # 0% - white
    gradient.setColorAt(0.4, QColor(100, 200, 255, 220))      # 40% - cyan
    gradient.setColorAt(0.7, QColor(50, 150, 200, 180))       # 70% - blue
    gradient.setColorAt(1.0, QColor(30, 80, 150, 100))        # 100% - shadow

    # Use it
    painter.setBrush(QBrush(gradient))
    painter.drawEllipse(QPointF(x, y), radius, radius)

================================================================================
PART 8: TESTING YOUR GRADIENT
================================================================================

Visual checklist for your bubble:

    ✓ CENTER is bright white - no cyan yet
    ✓ Transitions smoothly from white to cyan
    ✓ Cyan color is visible in the middle area
    ✓ Blue edge shows at ~70% point
    ✓ Edge fades to nearly transparent
    ✓ No hard color boundaries - smooth gradient
    ✓ 3D sphere appearance visible - not a flat circle
    ✓ Highlight appears top-left, not centered


If something looks wrong:

    Problem: Looks like a flat circle (no 3D)
    Cause: Highlight offset missing (using center instead of 0.3 offset)
    Fix: Change highlight calculation

    Problem: Colors too washed out
    Cause: Too much transparency at center
    Fix: Increase alpha values for 0% and 40% stops

    Problem: Colors too saturated / no fade
    Cause: Alpha values not decreasing properly
    Fix: Ensure alphas are: 255 → 220 → 180 → 100

    Problem: Doesn't look aquatic
    Cause: Colors not cyan enough
    Fix: Increase green and blue values: RGB(100, 200, 255)


================================================================================
PART 9: ANIMATION PERFORMANCE NOTE
================================================================================

For animated bubbles, DON'T recreate gradients every frame.

WRONG (slow):
    for bubble in bubbles:
        gradient = QRadialGradient(...)  # Creates new every frame!
        gradient.setColorAt(...)
        painter.setBrush(gradient)

RIGHT (fast):
    # Create once, reuse
    bubbles_gradient = {}

    def get_bubble_gradient(radius):
        if radius not in bubbles_gradient:
            gradient = QRadialGradient(...)
            # Set all color stops
            bubbles_gradient[radius] = gradient
        return bubbles_gradient[radius]

    # Then in paint loop:
    for bubble in bubbles:
        painter.setBrush(get_bubble_gradient(bubble.radius))


================================================================================
PART 10: TWEAKING THE GRADIENT
================================================================================

If you want to customize the appearance:

MAKE IT MORE OPAQUE (denser, less transparent):
    Original alpha:  255, 220, 180, 100
    More opaque:     255, 235, 200, 150

MAKE IT MORE TRANSPARENT (lighter, more glass-like):
    Original alpha:  255, 220, 180, 100
    More transparent: 255, 200, 150, 70

MAKE IT MORE CYAN (more aquatic):
    Original: RGB(100, 200, 255)
    More cyan: RGB(80, 210, 255)  (more blue and green)

MAKE IT MORE WHITE (more reflective):
    Original: RGB(255, 255, 255)
    Stay white for 0% and 40%:
    Original:  0% = RGB(255,255,255)  40% = RGB(100,200,255)
    More white: 0% = RGB(255,255,255)  40% = RGB(150,225,255)

TIGHTER HIGHLIGHT (more concentrated):
    Change highlight offset from 0.3 to 0.25
    x_highlight = x + radius * 0.25

BROADER HIGHLIGHT (softer):
    Change highlight offset from 0.3 to 0.35
    x_highlight = x + radius * 0.35

================================================================================
SUMMARY: THE MAGIC RECIPE
================================================================================

For convincing aquatic bubble effect:

1. CREATE radial gradient from highlight point (center + 0.3 offset)
2. SET color stops at: 0%, 40%, 70%, 100%
3. USE colors: white → cyan → blue → shadow
4. USE alphas: 255 → 220 → 180 → 100
5. DRAW ellipse with radius centered at bubble position

That's it! The gradient handles all the lighting and dimension.

Code pattern (from aquatic_effects_example.py):

    gradient = QRadialGradient(QPointF(x + r*0.3, y + r*0.3), r)
    gradient.setColorAt(0.0, QColor(255, 255, 255, 255))
    gradient.setColorAt(0.4, QColor(100, 200, 255, 220))
    gradient.setColorAt(0.7, QColor(50, 150, 200, 180))
    gradient.setColorAt(1.0, QColor(30, 80, 150, 100))
    painter.setBrush(QBrush(gradient))
    painter.drawEllipse(QPointF(x, y), r, r)

Copy this pattern for every bubble you draw.
