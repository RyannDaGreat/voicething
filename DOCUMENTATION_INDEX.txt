ESSENTIAL CONCEPTS AT A GLANCE
================================================================================

The Button Formula:
  1. Gradient 135°: light top-left → dark bottom-right
  2. Three shadow layers: inset light + inset dark + drop shadow
  3. White glossy shine at top-left (::before pseudo-element)
  4. Rounded corners (12px minimum)
  5. Smooth transition (0.3s cubic-bezier)

The Colors:
  Sky Blue:      #87CEEB → #0087BE (PRIMARY)
  Water Teal:    #40E0D0 → #00A896 (ALTERNATIVE)
  Grass Green:   #90EE90 → #228B22 (POSITIVE)
  Aurora Purple: #FFB6C1 → #87CEEB (SPECIAL)
  Neutral:       #FFFFFF → #D3D3D3 (BACKGROUND)

The Light Direction:
  ALWAYS 135° (top-left to bottom-right)
  Top lighter, bottom darker

The Shadow System:
  Layer 1: inset 0 1px 0 rgba(255,255,255,0.4)    ← Light top
  Layer 2: inset 0 -2px 0 rgba(0,0,0,0.1)         ← Dark bottom
  Layer 3: 0 2px 4px rgba(0,0,0,0.2)              ← Drop shadow

The Glossy Shine:
  position: absolute on button
  top: 0; left: 20%; width: 25%; height: 50%
  radial-gradient with white to transparent
  blur: 3px
  opacity: 0.6 default, 0.8 on hover, 0.3 on active

The Font:
  "Segoe UI", "Frutiger", "Helvetica Neue", sans-serif

The Easing:
  cubic-bezier(0.25, 0.46, 0.45, 0.94)

IMPLEMENTATION CHECKLIST
================================================================================

Before submitting your implementation:

Visual Quality:
  ✓ Buttons have visible white glossy highlights
  ✓ Buttons use 135° gradients (light → dark)
  ✓ All elements have 3-layer shadow system
  ✓ All corners are rounded (8px minimum)
  ✓ Colors are nature-inspired (sky, water, grass)
  ✓ Light source direction is consistent (top-left)
  ✓ Depth is visible through highlights, not just shadows
  ✓ Overall feeling is optimistic and friendly

Functionality:
  ✓ Hover states noticeably different
  ✓ Active/pressed states show depression
  ✓ Disabled states are desaturated
  ✓ Transitions are smooth (0.3s)
  ✓ Animations are natural (no jarring)
  ✓ No sharp edges or harsh corners

Accessibility:
  ✓ Text readable on all backgrounds
  ✓ Sufficient color contrast
  ✓ Text-shadow used for clarity on colored backgrounds
  ✓ Disabled states clearly indicated

Code Quality:
  ✓ Font stack includes Segoe UI/Frutiger/Helvetica Neue
  ✓ All transitions use cubic-bezier easing
  ✓ Whitespace is generous (not cramped)
  ✓ Consistent spacing (8px or 12px grid)
  ✓ CSS organized and maintainable
