KEY FINDINGS - QUICK REFERENCE

1. WAVEFORM VISUALIZATION TYPE
   Finding: LINE SEGMENTS (connected points), NOT dots or bars
   - Winamp oscilloscope rendered audio samples as polylines
   - Samples: 576 per frame (standard FFT window)
   - Update: 60 FPS
   - Rendering: QPainter.drawLines(points) with point array
   - Color: #00FF00 (pure lime green)
   - Background: #000000 (pure black for maximum contrast)
   - Enhancement: Semi-transparent glow layer at 2x width for neon effect

2. EXACT COLORS - WINAMP CLASSIC
   Neon Primary Colors:
   - Lime Green:  #00FF00 (RGB: 0, 255, 0) - THE iconic color
   - Cyan:        #00FFFF (RGB: 0, 255, 255) - Y2K secondary
   - Magenta:     #FF00FF (RGB: 255, 0, 255) - Y2K alternative
   - Yellow:      #FFFF00 (RGB: 255, 255, 0) - Spectrum end

   Backgrounds:
   - Black:       #000000 (RGB: 0, 0, 0) - Visualization background
   - Dark Gray:   #0a0a0a (RGB: 10, 10, 10) - Panel backdrop
   - Medium Gray: #1a1a1a (RGB: 26, 26, 26) - Main panel
   - Light Gray:  #333333 (RGB: 51, 51, 51) - Subtle highlights

   UI Controls (Windows 95):
   - Highlight:   #FFFFFF (RGB: 255, 255, 255) - Top-left bevel
   - Shadow:      #808080 (RGB: 128, 128, 128) - Bottom-right bevel
   - Button Face: #C0C0C0 (RGB: 192, 192, 192) - Standard gray
   - Peak Meter:  #FF0000 (RGB: 255, 0, 0) - Red indicator

3. WINDOWS 95 BEVELED 3D BUTTON EFFECT
   Principle: Light source from top-left corner
   
   Normal (Raised) State:
   - Top edge:    #FFFFFF white highlight (2px)
   - Left edge:   #FFFFFF white highlight (2px)
   - Bottom edge: #808080 gray shadow (2px)
   - Right edge:  #808080 gray shadow (2px)
   - Face:        #C0C0C0 button face color
   
   Pressed State (Inverted):
   - Top edge:    #808080 gray shadow (inverted)
   - Left edge:   #808080 gray shadow (inverted)
   - Bottom edge: #FFFFFF white highlight (inverted)
   - Right edge:  #FFFFFF white highlight (inverted)
   
   Implementation:
   - QSS/CSS: border-color properties with direction
   - Painter: drawLine() for top-left, then bottom-right

4. METALLIC/CHROME GRADIENT TECHNIQUES
   
   Chrome Effect (5-stop gradient):
   1. 0.0:  #FFFFFF - Bright highlight (light reflection)
   2. 0.2:  #E0E0E0 - Light transition
   3. 0.5:  #808080 - Mid-tone metallic core
   4. 0.8:  #404040 - Dark transition
   5. 1.0:  #000000 - Deep shadow

   Y2K Vaporwave (3-stop gradient):
   1. 0.0:  #00FFFF - Cyan
   2. 0.5:  #FF00FF - Magenta
   3. 1.0:  #FFFF00 - Yellow

   Implementation: QLinearGradient with setColorAt(position, QColor)

5. SPECTRUM ANALYZER BARS
   Type: Vertical bars for frequency bands (NOT waveform)
   Colors: Gradient from #00FF00 (green) to #FFFF00 (yellow)
   - Bottom of bar: #00FF00 (lime green)
   - Top of bar:    #FFFF00 (yellow)
   - Background:    #000000 (black)
   - Animation:     Smooth decay (85% old + 15% new per frame)
   - Typical bars:  32-128 frequency bands

6. CRT/LCD/LED DISPLAY EFFECTS
   
   Scanlines (CRT Monitor):
   - Spacing: 2-4 pixels between lines
   - Color: Black with ~10% opacity (0, 0, 0, 25 in RGBA)
   - Method: QPainter.drawLine() in loop

   LED Display Style:
   - Fonts: VT323 (pixel/LED style), LED Display, 7-Segment
   - Color on: #00FF00 (bright green)
   - Color off: #003300 (dark green, dim state)
   - Glow: Add semi-transparent copies offset by 1-3 pixels

   Glow Effect (Neon):
   1. Main text: Full opacity color
   2. Glow layer 1: -1 offset, 66% opacity
   3. Glow layer 2: +1 offset, 33% opacity
   Creates authentic neon/glowing appearance

7. FONTS FOR RETRO UI
   
   Primary Font: VT323
   - Monospace pixel font
   - Authentic Winamp aesthetic
   - Available: Free from Google Fonts
   
   System Fallback: Verdana 11px
   - Works on all platforms
   - Similar proportions to MS Sans Serif
   - Clean, legible
   
   Y2K Alternative: Orbitron
   - Geometric, futuristic
   - 16px bold for headings
   
   Font Sizes:
   - Window titles: 12px bold
   - Buttons: 10px normal
   - Numeric display: 14px bold monospace
   - Panel labels: 11px normal
   - Headings: 16px bold

8. PANEL BACKGROUNDS
   
   Modern Dark Blend:
   - Start: #1a1a1a (medium gray)
   - End:   #0a0a0a (dark gray)
   - Direction: Top to bottom linear gradient
   
   Optional Vaporwave Overlay:
   - Layer: Cyan -> Magenta -> Yellow gradient
   - Opacity: 5-10% (subtle, not overwhelming)
   - Effect: Adds Y2K character without destroying readability
   
   Beveled Border:
   - Top/left: #FFFFFF (1px white highlight)
   - Bottom/right: #333333 (1px gray shadow)
   - Creates inset/recessed appearance

9. SPECTRUM BAR IMPLEMENTATION DETAILS
   - 64-128 bars typical (frequency bands from FFT)
   - Each bar drawn individually with QLinearGradient
   - Smooth decay applied each frame (no sharp cuts)
   - Bar width: Total width / number of bars
   - Height: Normalized magnitude * widget height
   - Gap between bars: 1-2 pixels for definition

10. PERFORMANCE CONSIDERATIONS
    - Oscilloscope: ~100-576 line segments per frame (fast)
    - Spectrum: 64-128 gradients per frame (moderate)
    - Scanlines: Only if specifically needed (can reduce performance)
    - Update rate: 60 FPS typical (16ms per frame)
    - Use QPixmap buffering for complex scenes
    - Cache gradients if used repeatedly

class OscilloscopeWidget(QWidget):
    def paintEvent(self, event):
        painter = QPainter(self)
        painter.fillRect(self.rect(), QColor("#000000"))
        painter.setPen(QPen(QColor("#00FF00"), 1))
        painter.drawLines(self.waveform_points)
