TECHNICAL SPECIFICATIONS
================================================================================

Title Bar Dimensions:
- Win95/98/2000/XP: 19-21 pixels
- Vista/Win7: 27-30 pixels
- Win10/11: 32-36 pixels
- RECOMMENDED FOR YOUR APP: 28-30 pixels

System Button Dimensions:
- Win95-XP: 16x14 pixels
- Vista: 16x14 pixels
- Win7: 18x16 pixels
- Win10/11: 20x20 pixels
- RECOMMENDED FOR YOUR APP: 18x16 pixels

Window Resizing:
- Border width for resize detection: 5 pixels
- Cursor shapes: SizeHorCursor, SizeVerCursor, SizeFDiagCursor, SizeBDiagCursor
- Should disable resizing when maximized
- Minimum window size recommended: 400x300 pixels

Performance Considerations:
- Use Qt.RenderHint.Antialiasing for smooth gradients
- Cache gradient objects if they don't change
- Update only affected regions (not whole window)
- Test on high-DPI displays (125%, 150%, 200%)

COMMON ISSUES & SOLUTIONS
================================================================================

Issue: Buttons don't respond to clicks
Solution: Ensure buttons are added to layout and layout is set on widget

Issue: Window doesn't drag when clicking title bar
Solution: Check that mousePressEvent/mouseMoveEvent implemented correctly
         Verify self.pressed_pos is being set and used

Issue: Gradient colors look wrong
Solution: Verify exact hex/RGB values match reference
         Check gradient direction (should be top to bottom)
         Test on different monitors (colors may vary)

Issue: Transparency not working
Solution: Ensure using rgba() not rgb() for transparent colors
         Alpha values should be 0-255 (not 0-1)
         Test with specific opacity values from reference

Issue: Close button not red on hover
Solution: Check button type == "close" condition
         Ensure hover state painting code is executed
         Verify color values for hover state

Issue: Window resizing not working
Solution: Implement get_resize_edge() and mouseMoveEvent() handlers
         Verify cursor shape is being updated
         Test with 5-pixel border width

Issue: High DPI appearance issues
Solution: Use scalable fonts (not fixed pixel sizes)
         Test DPI scaling on actual Windows machine
         Adjust button sizes based on screen DPI if needed

Issue: Inactive window appearance
Solution: Check window.isActiveWindow() in paintEvent()
         Implement different colors when inactive
         Usually gray gradient with lower opacity
