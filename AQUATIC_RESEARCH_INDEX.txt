================================================================================
KEY FINDINGS SUMMARY
================================================================================

BUBBLE EFFECTS:
- Use QRadialGradient with 4 color stops (0%, 40%, 70%, 100%)
- Colors: White → Cyan → Dark Blue → Shadow
- Alphas: 255 → 220 → 180 → 100
- Highlight offset: 0.3 × radius from center
- Animation: Vertical float + horizontal drift + opacity fade

WET SURFACES:
- Layer 1: Base color gradient (light to dark)
- Layer 2: Frosted white overlay (35% opacity) - MOST IMPORTANT
- Layer 3: Specular highlight (tight, bright, 30% from top-left)
- Layer 4: Soft shadow below (Multiply blend mode)

AQUATIC COLORS:
- Primary: Cyan #00C8FF (RGB 0, 200, 255)
- Secondary: Turquoise #40E0D0 (RGB 64, 224, 208)
- Light: Light Aqua #AFEEEE (RGB 175, 238, 238)
- Dark: Dark Navy #003366 (RGB 0, 51, 102)
- Highlight: White #FFFFFF or Light Cyan #E6FFFF

VISTA AERO REFERENCE:
- Glass light: #E6F2FF
- Dark shade: #4A7BA7
- Highlight: #FFFFFF
- Accent: #0066CC

ANIMATION SPECS:
- Duration: 3-8 seconds per bubble
- Float: 150px upward over duration
- Drift: ±30px horizontal (sine wave)
- Opacity: 0% → 100% (fade in first 20%) → 100% → 0% (fade out last 20%)
- Timer: 40ms interval (25fps)
- Max bubbles: 20

PERFORMANCE:
- Separate widget for bubbles (no impact on main UI)
- Cache gradients (don't recreate every frame)
- Dirty region updates (not full redraw)
- No blocking of input/interaction
- Very lightweight

================================================================================
CUSTOMIZATION OPTIONS
================================================================================

If you want to modify the appearance:

Bubble sizes:
  - Change radius parameter: add_bubble(x, y, radius)
  - Larger = 20-50px, Medium = 10-20px, Small = 5-10px

Bubble count:
  - Add more/fewer add_bubble() calls
  - Recommended: 5-20 maximum

Colors:
  - Replace RGB values in gradient definition
  - Use AQUATIC_COLORS_VISUAL_REFERENCE.txt for alternatives
  - Test different cyan/blue ratios

Animation speed:
  - Change duration parameter in AnimatedBubble
  - Faster: 2-3 seconds, Slower: 6-8 seconds

Opacity:
  - Modify setOpacity() calls
  - More visible: 0.9, Less visible: 0.6

Placement:
  - Move add_bubble() calls to different positions
  - Avoid covering important UI elements

================================================================================
TROUBLESHOOTING
================================================================================

Problem: No bubbles visible
Solution: Check BubbleOverlay is created before painting
         Check add_bubble() is called after overlay creation

Problem: Bubbles appear behind content
Solution: Ensure BubbleOverlay is created AFTER main widgets
         Check z-order/stacking

Problem: Bubbles don't animate
Solution: Check timer.start() is called
         Check update_bubbles() is connected to timer

Problem: Performance issues
Solution: Reduce number of bubbles (max 20)
         Increase timer interval (up to 50ms)
         Check no other heavy painting

Problem: Colors look wrong
Solution: Verify RGB values match AQUATIC_COLORS_VISUAL_REFERENCE.txt
         Check display color space (sRGB vs other)
         Adjust alpha values if needed

Problem: Need to remove bubbles
Solution: Comment out bubble overlay initialization
         Remove from resizeEvent()
         No other changes needed
